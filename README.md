# Cosmetics Product Page

## Project Overview

Cosmetics Product Page is a responsive web-based cosmetics shopping interface designed to provide users with an attractive and simple way to view cosmetic products and their details.

The project was designed and developed using Figma Make and exported to GitHub for version control and deployment.

## Features

- Product image gallery
- Image navigation/swiping
- Product details
- Product price
- Shade/colour selection
- Quantity selection
- Add to Bag functionality
- Ingredients section
- Reviews section
- Responsive mobile interface
- Interactive buttons and navigation

## Technologies Used

- Figma Make
- React
- TypeScript
- HTML
- CSS
- Vite
- GitHub
- Vercel

## Project Structure

- `src/` – Main source code
- `public/` – Public assets
- `index.html` – Main HTML file
- `package.json` – Project dependencies and scripts
- `vite.config.ts` – Vite configuration

## How to Run the Project

1. Clone the repository.
2. Open the project folder in a terminal.
3. Install the required dependencies.
4. Start the development server.
5. Open the provided local URL in a browser.
